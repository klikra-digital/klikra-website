# KLIKRA Website Renovation V1

This directory contains an isolated visual renovation prototype for the KLIKRA website.

## Safety boundary
- Work branch: `renovasi-website-v1`
- Prototype path: `renovasi-website-v1/index.html`
- Production branch `main` is not modified.
- Existing NI SCHOOL / SARPRAS ADMIN 002 root `index.html` is not modified.
- Existing SARPRAS 001/002 application files are not modified.
- This is a design prototype, not a production deployment.

## Visual direction
- Background: `#F3F5FA`
- Main text: `#272B25`
- Olive accent: `#91A049`
- KLIKRA identity anchors: `#0B3D2E`, `#A7E22E`, `#F9F6EA`

## V1 scope
Responsive single-page concept with a desktop left sidebar, compact top utility bar, mobile header/dropdown navigation, KLIKRA Tower exhibition teaser on the homepage, learning journey section, eBook cards, and profile section. Header/sidebar use a compact vector logo mark in the KLIKRA green palette; homepage feature cards use a consistent inline-SVG line-icon system.

## Audit still required
